# HTML Kampus

Kumpulan tugas, latihan, dan project
pemrograman web selama perkuliahan
Teknik Informatika.

## Tentang Repository

Repository ini digunakan untuk menyimpan
berbagai tugas dan latihan selama mengikuti
mata kuliah Pemrograman Web Dasar.

## Daftar Folder

### 1. Tugas Individu
Berisi kumpulan tugas individu setiap pertemuan.

### 2. Tugas Kelompok
Berisi project dan tugas yang dikerjakan
bersama kelompok.

### 3. UTS
Berisi kumpulan tugas Ujian Tengah Semester.
